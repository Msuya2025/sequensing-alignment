# Sequencing Alignment Practical

Welcome! This repository contains the teaching materials, scripts, and data for our practical session on Sequencing Alignment.

## 📂 Repository Structure

*   **[01_Introduction](./01_Introduction)**: Contains the introductory presentation and notes.
*   **[02_Practical](./02_Practical)**: Contains the practical instructions and data.
    *   **[data](./02_Practical/data)**: Contains the clean_reads sequence reads.
    *   **[reference](./02_Practical/reference)**: Contains the FASTA reference genome.
    *   **[scripts](./02_Practical/scripts)**: Contains the bash scripts for alignment.

## 🚀 Getting Started

1. Read the practical instructions in the `02_Practical` folder.
2. Download the sample reads and reference files.
3. Use the scripts provided to run the alignment.

## ⬇️ How to Download Everything

If you want to download all the files at once, click the green **Code** button at the top right of this page and select **Download ZIP**.
